QUICK(ARR, N, BEG, END, LOC)
Here ARR is an array with N elements having its boundry values as BEG and END. We are having LEFTPTR and RIGHTPTR local variables that scan ARR with the variable at LOC. This algorithm gives the element at BEG position to its actual position in the array if it were sorted.

1.  [initialize pointers] 
    Set LEFTPTR = BEG
    RIGHTPTR = END
    LOC = BEG

2.  [Scan ARR from right to left]
    (a) Repeat while ARR[RIGHTPTR]>=ARR[LOC] and RIGHTPTR>LOC:
            RIGHTPTR = RIGHTPTR - 1
    (b) if RIGHTPTR=LOC, then: return
    
    (c) if ARR[RIGHTPTR] < ARR[LOC], then:
        (i) [interchange the values]
            set TEMP = ARR[RIGHTPTR]
            ARR[RIGHTPTR] = ARR[LOC]
            ARR[LOC] = TEMP
        (ii)[set new location]
            set LOC = RIGHTPTR
        (iii) go to step 3

3.  [scan ARR from left to right]
    (a) repeat while ARR[LEFTPTR]<=ARR[LOC] and LEFTPTR<LOC:
            set LEFTPTR = LEFTPTR + 1
    (b) if LEFTPTR = LOC, then: return
    (c) if ARR[LEFTPTR]>ARR[LOC], then:
        (i) [interchange the values]
            set TEMP = ARR[LEFTPTR]
            ARR[LEFTPTR] = ARR[LOC]
            ARR[LOC] = TEMP
        (ii)LOC = LEFTPTR
        (iii)   Go to step 2
